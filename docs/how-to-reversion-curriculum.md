# How To: Reversion Curriculum

You can edit the Title and Description without creating a new version

If you want to edit your structure, or add or remove items, you will be required to create a new version (unless no one has been assigned yet).

1. Navigate to the Menu > Content Management > Catalog page and click the Curriculum link
2. Search for your curriculum and click the *Edit* button on the right side
3. If desired, update the Title and Description fields
4. Click on the *Structure* page on the left navigation panel
5. Update the Structure details, or add or remove items as desired
